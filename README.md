# dungeonchain releases

Signed-off validator binaries for **dungeon-1**, published here when a release
must ship before its source does (for example a security fix under embargo).
Source for every binary is published to
[Crypto-Dungeon/dungeonchain](https://github.com/Crypto-Dungeon/dungeonchain)
once the upgrade is live; the commit in each `provenance.txt` will be there.

Always verify downloads against the release's `ASSET-SHA256SUMS` and the
extracted files against `SHA256SUMS`, and only stage a binary for an upgrade
plan that governance has approved.
